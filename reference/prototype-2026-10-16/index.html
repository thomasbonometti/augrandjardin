Testé sur un serveur Cloudflare local

La partie serveur ne tourne pas dans cet aperçu. Je l’ai donc lancée localement, avec le même moteur que Cloudflare :

  • Grille pro sans connexion : renvoi vers la page Professionnels
  • Mauvais mot de passe refusé, bon mot de passe accepté pour 60 jours
  • Cookie falsifié refusé, grille jamais indexée ni mise en cache
  • Commande incomplète refusée avec un message clair
  • Plus de 5 sacs refusé, variété épuisée refusée
  • Prix recalculés côté serveur : un prix trafiqué dans le navigateur est ignoré
